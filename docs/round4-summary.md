## 3. 新功能（8 项）

### 3.5 联网搜索（RAG 加强）
- `lib/search.ts`（博查 Web Search，8s 超时、失败不抛）+ `POST /api/search`。
- `/api/run` 收 `search` 开关，任务开始前先检索，结果以「【联网n】标题 / 摘要 / 链接」并入参考资料，调研员照常走 RAG 与引用标注。
- 顺序：**MCP `web_search`（真 MCP 调用）→ 失败退本地 `/api/search` → 再失败退模型知识**，任何一步失败都不中断任务。
- 结果区新增「已联网检索 N 条来源」+ 可点击来源列表；无 Key/关闭/无结果三种提示分别显示。
- 任务输入区新增「联网搜索」开关，默认开。

### 3.6 上传参考资料（PDF / Word）
- `lib/import-file.ts` 扩到 **10MB**，新增 `.docx`（mammoth，浏览器端解析，已实测 64 字）、保留 PDF（pdfjs-dist）与 TXT / Markdown。
- 文件只在浏览器本地解析，不上传服务器；解析结果进「已解析资料」列表（文件名 + 字数 + 移除），提交时合并进参考资料参与检索。

### 3.7 图片 OCR 进参考资料
- `lib/ocr-client.ts`：**Tesseract.js 优先**（`chi_sim+eng`，60s 超时），失败回退 `POST /api/ocr`（`lib/ocr.ts`，DeepSeek-OCR via SiliconFlow，需 Key）。
- 实测：上传一张带中文的活动通知图，识别出 25 字并生成资料条目；条目带图片缩略图、字数、移除。
- 无 Key 时 `/api/ocr` 返回 `configured:false`，前端提示「图片识别失败」，不中断任务。

### 3.8 MCP 工具集成（真实 MCP 调用）
- `mcp/server.mjs`：最小 MCP 服务器，**stdio + JSON-RPC 2.0**（按行分隔），实现 `initialize` / `notifications/initialized` / `tools/list` / `tools/call` / `ping`，暴露两个工具：`web_search`（博查）、`get_current_time`。
- `lib/mcp-client.ts`：以子进程拉起服务器，握手后 `tools/call`，7s 超时，结束后杀进程；失败返回 `ok:false` 由调用方降级。
- `/api/run` 每轮先调 `get_current_time`（把当前日期写进参考资料，时间敏感任务不再瞎猜日期），再调 `web_search`。
- 任务流右侧新增「工具」区，逐条显示 `工具名 / MCP 或本地直调 / 返回说明`。
- 实测：`get_current_time` 走 MCP 成功并回传 `2026-11-09T12:00:56Z`；`web_search` 因无 Key 报错 → 自动降级为本地直调 → 再降级为模型知识，任务照常完成。

### 3.9 单专家失败单独重试
- `/api/run` 新增 `mode:'resume'`：只重跑指定专家，成功后把结果并回已有结果，继续汇总 → 质检 → 修订。
- 专家区某专家 `failed` 时出现「重试 (n/2)」按钮，最多 2 次，重试中按钮禁用并显示「重试中…」；第 2 次失败保持失败态，任务继续并在汇总里注明该专家缺失。
- 「缺失说明」只在**真的被派了活又失败**时出现（本轮修掉了一个误报：未派活的专家曾被算作缺失）。
- 实测：直接打 `mode:'resume'`，事件序列 `research:running → expert → research:done → summarizer → qc → reviser → qc → done`。

### 3.10 修订前后对比
- `lib/diff.ts` 用 `diff` 包（`diffWordsWithSpace`）做词级 diff，输出 same / added / removed 三段。
- 结果区新增「对比修订」切换：有修订时出现，展开显示统计「共 N 处新增、M 处删除」+ 图例 + 逐词高亮（新增绿、删除红并划线）。
- 实测：一次真实修订（35 分 → 修订 → 91 分通过），diff 显示 183 处新增 / 222 处删除，DOM 中 20 个 added、21 个 removed 片段；`lib/diff.ts` 另有独立单测（`读书会周三/周四` → add 11 / del 1）。

### 3.11 语音输入
- 任务输入框右侧麦克风按钮，`Web Speech API`（`webkitSpeechRecognition`，中文 `zh-CN`、英文 `en-US`），识别结果追加进任务输入框；录音中按钮高亮并显示「正在听，说完再点一次」。
- 浏览器不支持时按钮不出现（能力探测在客户端做），出错只提示不报错。

### 3.12 历史搜索 + 分数筛选
- 任务历史加搜索框（按任务文字，带清除按钮）与三档筛选（全部 / 80+ 通过 / 未通过），全部本地过滤，不动 localStorage 结构；无匹配时显示「没有匹配的历史任务」。
- 实测：搜「读书会」剩 2 条；切「未通过」剩 0 条并显示空提示。

## 6. 拿不准 / 受限于环境的点

1. **联网搜索没有真实数据**：没有 `BOCHA_API_KEY`，只能验证「无 Key 时的降级与提示」这条路径。配好 Key 后 `/api/search`、MCP `web_search`、来源列表都会真实出数据，代码不用改。
2. **MCP 只验证到一个工具真实可用**：`get_current_time` 走 MCP 成功；`web_search` 的 MCP 路径因为没有 Key 只能验证「失败 → 降级」。要不要我再加一个不依赖外部 Key 的 MCP 工具（例如 `read_reference`）来把两个工具都跑通，等你定。
3. **DeepSeek-OCR 服务端路径没跑过**：没有 `SILICONFLOW_API_KEY`。浏览器端 Tesseract 已实测可用。
4. **语音只验证了按钮与能力探测**：无头浏览器无法真实录音，需要你本机点一次确认收音与转写。
5. **单专家重试的 UI 按钮**没有在真实失败场景下点到（模型这次都成功了），但 `resume` 接口链路已实测；按钮条件与计数逻辑按失败态渲染。
6. **专家失败计数**放在前端内存里（刷新归零），没有写 localStorage——如果希望刷新后仍记住「已重试 2 次」，告诉我。
7. **搜索关键词**现在直接用任务原文（截 160 字）；如果想让模型自己决定搜什么，可以放到调度官之后、用子任务目标去搜。
