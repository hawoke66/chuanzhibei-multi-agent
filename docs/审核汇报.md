## 六、建议的验收顺序（约 10 分钟）

1. `npm install` → `npm run build` → `npm run dev`（`:3000`）。
2. **首屏**：看链路五个标签是否都在星点侧边、六条线是否等粗、面板是否完整露出。
3. **滚动**：从顶滚到底，看翻页是否只播一次、页脚是否有星空、标语三行行距。
4. **派一次任务**（默认开搜索）：看任务流「工具」两条、结果区「未配置搜索 Key」、四项分生长、数字滚动、历史新增一条。
5. **上传三件套**：PDF/Word/TXT + 一张图片，看资料条目、字数、可移除。
6. **切 English 再跑一次**：界面、来源提示、输出正文是否全英文。
7. **历史区**：搜关键字、切「未通过」。
8. **修订对比**：若本次有修订，点「对比修订」看高亮。
9. **语音**：点麦克风说一句，确认进输入框。
10. 想验证真实搜索/OCR/MCP web_search：在 `.env.local` 补 `BOCHA_API_KEY`、`SILICONFLOW_API_KEY` 后重启。
