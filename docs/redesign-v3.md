# 网页结构大换血记录（v3，unslop 9 轮）

执行时间：2026-11-09。仓库回滚点：`3103154 chore: 结构大换血前回滚点`（父提交 `3e5bff8`）。

## 0. 事实核对

- 技术栈是 **Next.js 16.4.3（App Router）+ React 19.3 + Tailwind CSS 4**，不是 React + Vite。按硬性约束不迁移框架，改动全部落在 Next 里。
- 页面原来是一个单屏工作台：没有导航、首屏、页脚；所谓「专家卡」实际是 7 张等宽状态卡（调度 / 调研 / 文案 / 代码 / 汇总 / 质检 / 修订）。
- 本次把 7 张状态卡重组成 **4 张专家卡**（调度官一条宽幅 + 三位专家三条错落行）+ **任务流里的 3 个阶段节点**（汇总 / 质检 / 修订）。状态、事件、字段、计数逻辑一个没删。

## 1. 诊断清单（动手前扫描）

**字体**

- `globals.css` 用 `Arial, Helvetica, sans-serif`，是 skill 明确禁用的浏览器默认栈；Geist 已装却没用上。
- 全站 `font-bold` 与 `font-semibold` 混用，数字没有 `tabular-nums`，中英混排没有中文栈兜底。

**颜色与表面**

- 紫蓝渐变 3 处：提交按钮 `from-indigo-600 to-violet-500`、进度条 `from-indigo-400 to-violet-400`、底图 `starry-background.jpg` 本身是高饱和蓝紫星云（最典型的 AI 指纹）。
- 强调色不止一个：indigo + violet + emerald + red + amber；状态药丸用 `bg-emerald-50 / bg-red-50` 亮底，在深色页上像浅色主题残留。
- 一个「次要文字」有 5 种色值（`text-indigo-200`、`text-indigo-100`、`text-indigo-200/80`、`text-violet-300`、`text-indigo-50`）。
- 边框 `border-white/10 /15 /20 /25` 四档随手写；卡片底 `slate-950`、`slate-950/70`、`slate-950/80` 三种近似黑。
- `shadow-lg / shadow-xl` 11 处、`drop-shadow` 1 处；深色主题本该用表面层级 + hairline。
- 错误块 `bg-red-50` 浅色面直接插进深色页。

**布局**

- 全站单列 `max-w-4xl` 居中堆叠；7 张状态卡 `w-[calc(50%-6px)]` 强制 4 列等宽；适用场景 3 张等分卡；AI 亮点 5 张等分卡。
- 没有首屏、导航、页脚；没有负边距层叠；结果区 4 张 `MetricCard` 等分；历史每条一张卡。

**交互与状态**

- hover 只有 `hover:bg-white/20`，没有 active、没有 `focus-visible` 焦点环；`transition-all` 5 处；`animate-pulse` 1 处；进度条动 `width`（布局属性）。
- 没有空状态（未派任务时结果区整段消失）、没有骨架屏；删除按钮是 `×` 字符。

**文案**

- 副标题「提交任务后，7 张状态卡会随执行进度实时更新」用实现细节代替价值。
- 没有定位句；「AI 技术亮点」是自夸标签；适用场景 3 条是功能说明，不是真实用户；大量「xxx：」全角冒号拼接。

**组件模式**

- 一套「`rounded-2xl + border-white/20 + bg-slate-950 + shadow-lg`」卡片模板全站复制粘贴；药丸按钮遍地（提交 / 取消 / 复制 / 导出 / 清空 / 导入 / 示例 / 删除 / 语言切换）。

**图标**

- 全站零图标（只有 `×` 和 `01-05` 编号），专家无标识，空状态无插画。

**代码质量**

- 45KB 单文件承载全部区块；`style={{ width }}` 动布局属性；任意值 `text-[11px]`。

## 2. 方向五句话

- **产品**：多智能体协作台——一个任务派出去，调度拆成子任务，调研、文案、代码并行完成，质检 80 分以上才交付；给预算和人力都不宽裕的小团队、学生小组、个人工作室用。
- **性格**：精确、克制、整夜值守。
- **世界**：深夜天文台的观测舱——星图、方位刻度、细白线条、仪表读数；中性色往夜蓝 tint，强调色只留「观测灯」那一支浅紫。
- **亮点**：① 动态星空（分层星、淡银河带、星座连线、左下小行星、右上流星，闪烁 + 缓慢漂移）；② 协作可视化（四位专家到质检的星座式连线，状态靠星点亮）。
- **签名**：四角星状态点（等待空心、进行中微亮带环、完成满亮、失败暗红、未参与半透明），全站统一，只此一个。

## 3. 九轮改动

### 第 1 轮 间距

- 全部改用 4px 网格：区块 `py-20 / py-24 / py-32`，组内 `gap-2 / 3 / 4 / 6`，组间 `mt-12 / 14 / 16`；删掉 `-mt-[13px]` 一类一次性数值（原本没有，新增代码也没引入）。
- 同类元素同尺寸：专家行统一 `py-6`；质检记录、任务历史、插件行统一 `py-3 / py-4`。
- 组内小于组间：专家区标题与列表 56px，列表与进度条 40px；结果区标题与正文 40px，正文与专家输出 40px。
- 底部留白略多于顶部：页脚 `pt-20 pb-24 lg:pb-28`。

### 第 2 轮 颜色

- 建立一套往夜蓝 tint 的中性色阶，写在 `app/globals.css` 的 `:root`：`--void #05070f`、`--surface #0a0e1a`、`--raised #111827`、`--line / --line-2`（文字色 8% / 14% 的 hairline）、`--ink / --ink-2 / --ink-3` 三个文字角色、`--accent #a99bf5` 一个强调色、`--ok / --warn / --danger` 三个只表态的语义色。
- 删掉全部紫蓝渐变（按钮、进度条）、全部 `shadow-*` 与 `drop-shadow`、全部亮底药丸。
- 深度只用表面层级 + hairline，不用阴影。
- 底图从高饱和蓝紫星云压成安静底噪：`filter: saturate(0.4) brightness(0.4) contrast(1.08)`，星空本身靠 canvas 粒子层承担。
- 强调色用于：导航星标、总体进度、质检条、评分条、开关、焦点环；正文不铺强调色。

### 第 3 轮 图标

- 引入 `@phosphor-icons/react@2.1.10`（先查 `package.json` 确认没有图标库，registry 可达后安装），全站一套、一种字重（regular）、两个尺寸（16 / 18）。
- 删除用 `×` 字符当删除按钮、用数字当编号图标的做法；表情符号全站为零。
- 图标颜色一律跟文字角色（`text-ink-2 / text-ink-3`），不自带颜色；图标盒宽一致，与文字间距固定。

### 第 4 轮 文案

- 首屏定位句用硬性要求原句：「让小团队低成本拥有一个 AI 团队」，断行断在「让小团队 / 低成本拥有一个 AI 团队」。
- 适用场景重写为真实用户：学生团队（课程项目与比赛备赛）、个人工作室与初创团队（没预算也要交完整方案）、老师与社团（活动材料散在聊天记录里），每条一句话场景 + 一句话「协作台帮你做什么」。
- 删掉 hype 词与自夸标签（「AI 技术亮点」改为「任务流 · 从一句话到一份成果」）；短标签、按钮、副标题去掉结尾句号；界面无感叹号、无问候式标题、无 `PRO / New` 徽章；数字统一千分位、小数一位。
- 新增中段大字标语（B11）：三行「派一个任务出去，/ 四个专家同时开工，/ 判断留给你自己」，滚动进入时逐行从 30% 淡色过渡到全色。

### 第 5 轮 字体

- 英文用已装好的 Geist，中文补系统无衬线栈（PingFang SC / 微软雅黑 / 思源黑体），元信息与数字用 Geist Mono。
- `globals.css` 里用 `@utility` 定义一套命名文本样式：Heading 1-6、Title 1-4、Body 2/3/5/6、Caption 1/2/4/5、Button-md/sm，字号全部落在 Tailwind 默认阶梯，行高取该档自带值。
- 字重只到 600，标题靠字号和颜色拉层次；无斜体、小字无负字距；数字一律 `tabular-nums`。

### 第 6 轮 布局

- 总容器 `max-w-7xl`（1280px），首屏标题与副标题上限 680px。
- 首屏改非对称分栏：左侧文案（6 栏），右侧协作链路图（6 栏），`min-h-dvh` 铺满首屏。
- 任务输入不做卡片：一块宽幅悬浮面板，用 `-mt-8 / sm:-mt-12 / lg:-mt-20` 与首屏轻微层叠。
- 专家区一大三小：调度官一条带表面色的宽幅，三位专家是错落的行（角色文字分别从第 4 / 5 / 4 栏起），没有一张等宽方块。
- 任务流：五节点横向刻度轨道 + 左侧调度计划 + 右侧阶段状态，不做五等分卡片。
- 结果区改文档式长卷：左侧 7-8 栏正文，右侧 4 栏质检读数，宽窄不等。
- 任务历史改时间线列表（序号 + hairline 分隔 + 删除）。
- 适用场景三张不同容器、非对称落位：表面块 / 只有 hairline 起头的文字块 / 抬升块，第二张下沉、第三张前移，形成错落。
- 插件中心用 hairline 分行列表，不做卡片。
- 各区间用负边距轻微层叠（任务输入、结果区、第三张场景卡）。

### 第 7 轮 细节

- 圆角只用 Tailwind 值：控件 `rounded-lg`（8）、内嵌块 `rounded-lg / xl`、面板 `rounded-2xl`（16）；嵌套按「内 = 外 − 间距」。
- 计数与元信息改安静文字（mono + 次级色），不再用发光药丸。
- 焦点环：所有可交互元素 `focus-visible:outline-2 outline-offset-2 outline-accent`。
- loading 用与真实布局同形的骨架屏（结果区标题、正文行、右键读数块），不用转圈。
- empty 用有引导的「还没有成果」视图：说明 + 四个待填指标 + 三步指引 + 去派任务。
- error 行内具体报错 + 重试按钮，不用 `window.alert`。
- 导航改悬浮胶囊：离顶 16px、居中、按内容定宽、半透明 + 背景模糊；小屏收成按钮，展开全高面板，链接按阅读顺序每 60ms 依次到位（上限 400ms）。

### 第 8 轮 视觉

- 星空是唯一「亮」的东西：`dynamic-background.tsx` 重写为 canvas 分层星（远 / 中 / 近三层，越近越大越亮、漂移越快）+ 斜向银河带（沿斜线撒的密集微星，不用渐变色块）+ 三组星座连线 + 左下小行星（暗面 + 边缘光 + 两个坑）+ 右上流星（14 到 26 秒一颗）。
- 银河照片只作图片层，压暗去饱和后当底噪，不再是视觉主体。
- 首屏右侧协作链路图用 SVG 画：调度官四角星在顶、三位专家成一条横线、质检官在底，连线即真实数据流；无装饰性插画、无光晕、无玻璃质感。
- `prefers-reduced-motion` 下只画一帧静态星空，不跑 requestAnimationFrame，不做位移动画。

### 第 9 轮 动效

- 全站一条缓动曲线 `cubic-bezier(0.22,1,0.36,1)`，位移 500ms、颜色与透明度 300ms，最短 200ms；没有 `ease / linear / ease-in-out`。
- 删掉 `animate-pulse`（进行中状态改用「实心星点 + 细环」静态表达）、`transition-all`、卡片 `hover:scale`、`drop-shadow`。
- 滚动显现：每区进入视口上浮 32px + 淡入，700ms，只播一次，用 IntersectionObserver；另加一条 rAF 节流的滚动兜底扫描，解决平滑滚动 / 锚点跳转时 IO 不触发导致整片空白的问题（实测跳转到 3200px 时全部上方区块正确点亮）。
- 整页只有一次入场节奏：各区块上浮 32px，同区内部仅 60 / 80 / 90ms 的小 stagger。
- 进度条与质检条改用 `transform: scaleX()`，不再动 `width`。

## 8. 拿不准、等验收定的视觉选择

1. **首屏标题字号取 Heading 2（48px）而不是 Heading 1（60px）**：定位句 13 个字，60px 在 680px 上限内会折成三行且行高 1:1 偏挤，48px 两行更稳。如果更想要压迫感，可以换 60px 并放宽到 720px。
2. **星空底图保留为图片层（压暗去饱和）**：硬性要求是「星空主题保留」，skill 又反渐变；保留真实银河照片当底噪、把星星/连线交给 canvas，是两者折中。如果验收认为照片仍偏紫，可直接删 `public/starry-background.jpg` 的引用，只留 canvas 粒子层。
