## A. 滚动翻页

- 实现：`ui.tsx` 里一个模块级的 rAF 循环 + 一条 passive `scroll`／`resize` 监听（没有用 `animation-timeline: view()`，为了 Safari 也能一致）。每个区块按自身位置算进度 `p = (视口高 − 区块顶 − delay×0.35) / max(240, 视口高×0.55)`，夹在 0–1。
- 三个量同时发生：`rotateX(12°→0)`、`scale(0.96→1)`、`opacity(0.08→1)`，`transform-origin: top center`，`perspective(1400px)`，只写 `--reveal-p` / `--reveal-angle` 两个自定义属性，只影响 transform 与 opacity。
- 播完即定格：`p` 到 1 后把该区块移出集合并打上 `data-settled="true"`，之后滚动不再更新，回滚不重播；全部播完后监听自动摘掉。
- 不锁滚动：没有用 `scroll-snap`，滚动保持自由。
- 移动端（<768px）：角度减半到 6°。
- `prefers-reduced-motion: reduce`：不翻折、不位移，只留一次 420ms 淡入。
- 实测（1440）：18 个区块全部 `settled`，最小 `--reveal-p` = 1；滚动过程中同一批区块的进度依次为 0 → 0.27 → 0.65 → 1，角度 12° → 8.7° → 4.2° → 0°。
- 实测（390）：角度 6°（减半），进度同样 0 → 0.49 → 0.93 → 1。

## B. 状态动效

1. **协作链路电流 + 节点依次点亮**（hero）：每条连线叠一条 `pathLength=100` 的亮线，`stroke-dashoffset` 从 0 跑到 -116（一次性），按 调度→调研/文案/代码→质检 的顺序错开 420/500/580 → 1220/1290/1360ms；节点 180 → 900/960/1020 → 1700ms 依次 pop 出现，名字晚 120ms。
2. **星空视差**：鼠标位置归一化后逐层偏移，三层星点分别 1.7／3.4／5.1px（在 3–5px 区间），银河层 6px；滚动时银河层按 `-scrollY × 0.06` 缓慢上移，星点按层再叠一点。实测鼠标从左侧移到右侧，银河层 transform 从 `translate3d(0px, 0.76px)` 变到 `translate3d(2.32px, -0.4px)`。
3. **数字滚动**：耗时、字数、Token（prompt + completion）、质检分都从 0 tween 到目标值（900ms，easeOutCubic）。实测一次运行：质检分 0 → 27 → 67 → 92；另一次 0 → 60 → 90。
4. **质检进度条生长**：总分条与四项分条都从 `scaleX(0)` 长到目标值，总分 700ms、四项分每条错 90ms。实测 0 → 0.33/0.56/0.75/0（250ms）→ 0.80/0.90/0.95/0.95（750ms）。
5. **任务流光点**：轨道进入视口时（`IntersectionObserver`，threshold 0.3），五段细线依次从 0 拉到 1（每段错 150ms），段尾出现一个 4px 光点，序号从 `ink-3` 亮到 `ink-2`。
6. **结果文字逐段淡入**：`.md-view` 的直接子节点逐段 `translateY(8px)` + 淡入，前 8 段按 80ms 递增延迟（实测 0.04s / 0.12s / 0.20s）。
7. **按钮与卡片**：主按钮（首屏 CTA、提交任务）hover 时一条窄光斜扫而过（只动 transform 与 opacity）；模板按钮与专家开关 hover 上浮 2px 并把边框提到 `line-2`。

## C. 明确没加 / 没做的

- 没加全屏循环脉动、呼吸光晕、漂浮元素、弹簧动效、`transition-all`、卡片 `hover:scale`。
- 循环动效只有一处：进行中状态的星点外圈微光（2.4s），`prefers-reduced-motion` 下关闭。
- 专家区、适用场景、插件中心的标题没有做逐字升起：它们所在文件不在本轮的允许范围（`experts.tsx`、`scenarios.tsx`、`plugin-center.tsx`），需要下一轮才能改。
- 卡片 hover 上浮只落在允许文件里的「小块卡片」（模板按钮、专家开关）；插件行与场景卡的 hover 同样需要那几个文件。

## 拿不准、等验收定

1. **翻页进度窗口取「视口 55%」**：区块顶到视口 45% 高度处才翻完，读起来是「一边滚一边展开」。如果觉得太慢，可以把 `ui.tsx` 里的 `0.55` 调到 `0.4`，翻得更早、更快到位。
2. **链路电流是一次性的**（开场跑一遍就停），没有做持续流动；持续流动会变成常驻循环动效，按 B 组的要求只允许在进行中状态上出现。要持续流动我再单独加一个「仅运行中」的开关。
3. **主按钮微光用浅紫**（`--accent` 45% 透明），在米白按钮上是淡淡一层；如果想更明显，可以换成白色高光并把透明度提到 60%。
4. **手机标题逐字升起**：390px 下标题 30px、13 个字逐字 30ms，总时长约 0.6 秒；如果嫌碎，我可以改成按短语（2–3 个）升起。
5. **卡片 hover 上浮范围**：本轮只覆盖允许文件里的模板按钮与专家开关；插件行、场景卡、结果区代码块的 hover 是否也要加，等下一轮把对应文件放开再定。
